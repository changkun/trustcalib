# Progressive Autonomy as Preference Learning: Experiment Report

Generated by `uv run python -m experiment.run`. Stream length N=1500; 10 seeds for the main tables, 20 paired seeds for the acquisition probe. Every number below is recomputed from the code; nothing is tuned on labels.

## Protocol

- Oracle: probit approval `Phi(f*)`, `f*` = static action acceptability + saturating trust with an abrupt reset at t=750 + a three-way veto (irreversible AND sensitive AND low trust) + task offset (`experiment/oracle.py`).
- Phases: warm-up `[0,560)` (not scored); scored early `[560,1050)` (contains the changepoint) and late `[1050,1500)`. Prequential: every decision is logged before any label at that step exists.
- Thresholds from Chow costs (Proposition 2). Symmetric: c_FA=c_FB=2.857, c_ask=1, band (0.35, 0.65). Safety-weighted: c_FA=10, c_FB=4, c_ask=1, band (0.25, 0.9).
- Regret = mean Chow loss of the gateway's decisions minus that of the oracle policy that knows `Phi(f*)`, in units of one escalation.
- Hyperparameters: `l_tool=1.1`, `l_ctx=1.2` throughout. Product: σ²=1.6, λ=90. Additive (fixed before any run): σs²=1.6, σg²=1.0, σd²=0.6, λ=90. Evidence-selected (EB) models re-select by Laplace marginal likelihood every 64 labels over: product σ²∈{1.6,3.2} × λ∈{60,120,240,480,960}; additive splits ((1.6, 1.0, 0.6), (3.2, 1.0, 0.6), (1.6, 2.0, 0.6), (1.6, 1.0, 1.6)) × λ∈{60,120,240,480}; linear λ∈{60,120,240,480}.

## Limitations

- Simulation only; the oracle is synthetic and additive by construction, so the additive kernel's advantage is indicative, and a linear probit with the same time structure is competitive on average metrics because the oracle's static term is linear in the features.
- Veto-window numbers rest on few actions per seed (the veto is active for ~90 steps after the reset); read them as directional.
- Costs are stated, not elicited; the two operating points bracket plausible choices.
